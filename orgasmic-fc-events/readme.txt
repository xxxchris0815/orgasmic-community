=== ORGASMIC Community Kalender ===
Requires at least: 6.4
Requires PHP: 8.1
Stable tag: 1.0.5
License: GPLv2 or later

Event calendar for FluentCommunity with space visibility, RSVP, Zoom S2S, feed sharing, reminders, and REST API.

== Changelog ==

= 1.0.5 =
* Mobile nav shows the calendar glyph instead of an empty blue circle

= 1.0.4 =
* Brand name corrected to ORGASMIC.

= 1.0.3 =

* Mobile layout: compact month grid, larger tap targets, list-first cards

= 1.0.2 =

* Events stay on the local calendar day (timezone)
* Date/time pickers; admins can click a day to create an event

* Activity stream posts via FluentCommunity FeedsHelper
